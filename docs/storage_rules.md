# 저장 위치 규칙 (GitHub vs 구글 드라이브)

GitHub = 2차 문서(색인·키워드·링크·결정 요약·일정·팁). 정제된 정보와 원본 = 회사 구글 드라이브.

| 정보 | GitHub | 드라이브 | 비고 |
|---|---|---|---|
| 문서 목록·링크·요약·키워드 | O | | 색인 본체 |
| 결정 요약(무엇을 왜) | O | | 금액·조건은 빼고 "원본 참조" 링크 |
| 일정·마감일 | O | | |
| 업무 팁·노하우 | O | | |
| 단가·견적·계약 조건·청구 금액 | X | O | 링크만 |
| 계정·비밀번호·API 키·라이선스 키·Wi-Fi 키 | X | O(보안 폴더) | 절대 금지 |
| 직원·고객 개인정보(전화·주소·SSN·급여) | X | O | 업체 담당자는 이름·직함까지만 |
| IP 대역·방화벽 설정·네트워크 구성도 | X | O | 보안상 |
| POS·결제 관련 세부(PCI 범위) | X | O | |
| 법적 분쟁·인사 관련 | X | O | |
| 이메일 원문 | X | O(또는 메일함) | GitHub엔 요약만 |

애매하면 드라이브로 보낸다. Claude는 작성 중 해당 정보를 발견하면 빼고 "드라이브 보관 추천"이라고 알린다.
