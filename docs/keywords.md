# 키워드 표준 목록

같은 뜻은 한 단어로 통일. 새 키워드는 여기 먼저 추가한 뒤 사용. 형식: `#키워드`

| 분류 | 키워드 |
|---|---|
| 업체 | #vendor-<이름> (예: #vendor-ncr) |
| 매장 | #store-<약칭> |
| 분야 | #pos #network #hardware #software #security #license #contract #billing #support |
| 종류 | #decision #schedule #issue #tip #meeting #email |
| 상태 | #open #done #waiting |
