## 판정 순서 (메일마다 하나, 스레드의 현재 상태로 점검 때마다 다시 판정)
1. 할 일 → 기록 건 `#open`
2. 기다림 → `#waiting` + "대상: 누구" (사용자가 확인해 줄 때만. 기본은 할 일)
3. 참고 → 한 줄 또는 건수만 (IT 조직 관련은 "우선 높음")
4. 자동·버림 → daily_log "메일 점검" 줄에 건수만
- 표시: ⚠ 보안 위험(보고 맨 위, 값은 기록 금지) / →kb 후보(승인 후 kb로)
- 상대·분야는 기존 태그(#vendor- #store- #network …). 분류 코드는 저장소에 남기지 않음
- 애매하면 한 단계 위로 올리고 보고에 "추측"
- CC만 받은 스레드 = 참고. 내 이름·요청이 나오면 할 일로
- 같은 건이 여러 메일함에 있으면 한 건으로
