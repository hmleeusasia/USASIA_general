# 월초 드라이브 점검 (drive-check, D-20261102-21)

읽기 위주. 드라이브 복원·삭제·공유 변경은 하지 않는다(사용자가 함). 결론 먼저, 표로 보고.

## 1. 링크 점검 (Haiku 하위 에이전트, docs/kb/subagents.md)
- 대상: docs/drive-index/*.md 의 모든 드라이브 링크에서 파일·폴더 ID를 뽑는다 (claude-folder.md 포함)
- 에이전트에게 ID 목록을 주고 ID마다 get_file_metadata (+ 색인에 공유 열이 있는 것은 get_file_permissions)
- 보고 받을 것: ID별 상태 = 정상 / 휴지통(trashed) / 없음(조회 실패) / 이름 바뀜(새 제목) / 공유 바뀜(소속·인원수만, 이메일 주소 금지)
- 수정일이 지난 점검 이후인 것은 "내용 변경 → 색인 갱신 후보"로 함께

## 2. 결과 처리 (지휘)
- 휴지통·없음: 색인 행을 지우지 않고 문서 이름 앞에 `🗑삭제됨(YYYY-MM-DD 확인)` 표시. 보고 맨 위에 "30일 안에 복원 가능" 안내. 사용자가 의도한 삭제라고 하면 그때 행 정리
- 이름 바뀜: 색인의 문서 이름 고침
- 공유 바뀜: 색인 공유 열 고침. 회사 밖 공유가 늘었거나 ⚠민감 문서면 보고 맨 위(⚠)
- 내용 변경: 중요 문서만 다시 읽어 색인 고칠지 사용자에게 제안

## 3. Claude 폴더 월 백업
- 10_주소록, 90_변경대기 시트를 copy_file로 같은 Claude 폴더에 `99_백업_YYYY-MM_<원래 이름>` 사본 (사용자 승인 후)
- 사본 만든 뒤 get_file_permissions로 소유자만인지 확인. 다른 사람이 있으면 멈추고 보고
- 백업은 최근 3개월치만 두고, 오래된 것은 지우자고 사용자에게 제안(Claude가 지우지 않음)

## 4. 끝
- 색인 수정 커밋·push
- CURRENT_STATE H절 "마지막 월초 점검"을 이번 달(YYYY-MM)로 고침
